One haiku about debugging — three lines in the 5-7-5 syllable shape, at most 200 characters — written by a small Python program for make.fun's "Seventeen Syllables of Debugging" bounty ($5 in USDC). The program writes the haiku to `/output/entry.txt`; a judge model compares entries two at a time on form, a concrete central picture, the turn in the last line, and fresh wording.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Deterministic: the same bytes on every run. Standard library only, no network, no randomness.
